# Xianyu 1.3.5

## 综合修复版

### 登录与云端鉴权

- 修复云端登录成功后刷新页面或续期时跳回登录页的问题。
- 保留云端系统登录鉴权，同时禁止闲鱼 Cookie/Token 同步到云端。
- 刷新令牌继续携带云端会话，确保多台设备登录状态一致。

### 更新流程

- 检测到新版本后自动进入下载、安装和服务校验流程。
- 客户端维护包不再伪装成最终完成，而是进入明确的启动器交接状态。
- 更新器自动关闭并重新启动主启动器，应用新版客户端文件。
- 客户端交接后继续执行延迟的运行时镜像同步，避免出现“界面已升级、Docker 仍是旧镜像”。
- 修复更新完成后进度条继续滚动、窗口不退出的问题。
- 修复检查阶段回滚保护徽标一直显示“检测中”的问题。
- 继续兼容 1.2.0、1.3.0、1.3.1、1.3.2、1.3.3 和 1.3.4 的升级路径。
- 运行时同步完成后清理遗留同步标记，避免反复停留在 2/6。

### 内置 AI 自动回复

- 继承 1.3.4 的内置 AI 开关持久化修复。
- VIP/管理员开启后自动加载内置关键词和预置话术，刷新后状态不丢失。
