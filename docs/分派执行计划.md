## 0. 目标与原则
- **目标**：在 `D:\xianyu-rewrite` 全新重写一套与原仓库功能对齐的系统，代码/文案/表结构/页面全部重写，仅复用“通用想法”（多账号、自动回复、发布、订单、采集、监控、通知、风控、定时）。

## 1. 技术选型（已验证可跑）
- 后端：Python 3.11 + FastAPI + SQLAlchemy 2.0 + asyncmy + Redis 7 + APScheduler
- 自动化：Playwright / Patchright（仅发布/验证场景；接口场景走 mtop 协议直连，按当前工程独立实现）
- 前端：React 18 + TypeScript + Vite + TailwindCSS + Zustand + React Router
- 基建：MySQL 8 + Redis 7 + Nginx（前端静态 + /api 代理）
- 部署：`docker-compose.yml` 一键起 6 容器；`frontend/dist` 直上 Cloudflare Pages；`deploy/functions/api/[[path]].js` 代理 `/api` `/static` 到后端公网

## 5. 接口契约（所有 Agent 遵守）
- 前缀：`/api/v1/*`，响应统一 `{success, code, message, data}`

- 鉴权：`Authorization: Bearer <JWT>`，`JWT_SECRET` 读 env

- WebSocket：`ws://backend:8089/api/v1/ws` 或直连 `websocket:8090`（二选一，文档注明）
